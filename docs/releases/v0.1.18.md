Minamo v0.1.18 adds a reproducible smoothing-filter baseline and publishes the
latest fully integrated main after the v0.1.17 release-contract refactor.

## Filter response benchmark

- `pnpm bench:filters` now measures jitter attenuation, step lag, overshoot,
  sustained-motion error, and one-frame outlier passthrough on a deterministic
  60 fps workload.
- `pnpm bench:filters --sweep` evaluates the One Euro parameter space against
  every shipped preset without changing runtime defaults.
- English and Japanese benchmark reports document the measured baseline and
  the acceptance bar for any future learned-filter candidate.

## Research decision

- One Euro remains the default across all live channels.
- HPSTM and SmoothNet are ruled out for the live path because they require
  future-frame windows.
- FLK remains the only live candidate and is scoped to pose keypoints, where it
  must improve outlier handling at matched jitter and lag before adoption.

## Release reliability

- Release metadata validation remains centralized and testable.
- Native installers remain serialized, with signed updater entries required for
  Linux, Windows, Apple Silicon macOS, and Intel macOS before publication.

## Verification

- `pnpm lint`
- `pnpm test`
- `pnpm verify`
- `pnpm typecheck:js`
- `pnpm build`
- `pnpm bench:filters --sweep`
- `pnpm release:smoke`
- GitHub Actions CI, Pages, release matrix, and updater-manifest validation

## Known limitations

- Windows and macOS installers still lack publicly trusted developer
  certificates. SmartScreen or macOS Privacy & Security approval may be
  required even though in-app update artifacts are cryptographically verified.
- macOS packages are ad-hoc signed but not notarized; Linux packages are not
  GPG-signed.
