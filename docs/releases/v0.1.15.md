Minamo v0.1.15 completes the desktop security-hardening work with signed,
in-app updates and makes the native release pipeline retry-safe.

## Security and updates

- Minamo Studio can check GitHub Releases for updates, ask before installing,
  verify the downloaded platform artifact with its embedded minisign public
  key, and restart into the new version (#251).
- The desktop capability exposes only updater check/install and process
  restart; shell access and process exit remain unavailable.
- Release CI reads the updater private key only from GitHub Actions secrets and
  publishes signed Linux, Windows, Apple Silicon, and Intel macOS update
  artifacts with a merged `latest.json`.

## Release reliability

- Tagged release retries now own one draft lifecycle, tolerate an existing tag,
  avoid stale native target caches, and ignore deleted release refs
  (#329–#333).
- A public release still appears only after every installer and signed updater
  artifact has completed.

## Verification

- `pnpm lint`
- `pnpm test`
- `pnpm verify`
- `pnpm typecheck:js`
- `pnpm build`
- `pnpm desktop:check`
- `pnpm release:smoke`
- GitHub Actions release matrix and updater-manifest validation

## Known limitations

- Windows and macOS installers still lack publicly trusted developer
  certificates. SmartScreen or macOS Privacy & Security approval may be
  required even though in-app update artifacts are cryptographically verified.
- macOS packages are ad-hoc signed but not notarized; Linux packages are not
  GPG-signed.
