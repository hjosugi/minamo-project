Minamo v0.1.13 strengthens protocol correctness, automated verification,
localization, and the dependency baseline.

## Reliability and protocol

- KGM1B readers now fail closed on unknown format versions, with shared
  JavaScript, Rust, and Python conformance vectors (#256, #257).
- The shipped browser runtime has deterministic coverage gates, page-entry and
  replay smoke tests, and extracted pure-logic tests (#263).
- CI asserts that raw webcam values cannot reach network sinks (#264).
- Desktop/avatar diagnostics complete the English/Japanese runtime localization
  pass (#267, #307).

## Maintenance

- Updated GitHub Actions to their Node.js 24 generations and refreshed the
  pnpm action (#287-#291).
- Updated relay Rust dependencies, Tauri dependencies, and the root
  TypeScript/Vite/Vitest toolchain (#292-#295).
- TypeScript 7 now sees the KGM1 decoder's concrete `KgmFrame` result instead
  of the legacy `object` annotation.

## Verification

- All six GitHub Actions jobs passed for the final TypeScript 7 pull request:
  JavaScript, Rust, desktop, relay-node, Docker, and security audit.
- Local TypeScript 7 checks, lint, unit and structure tests, privacy invariant,
  coverage gate, repository verification, and production build passed.

Manual browser/camera, desktop-GUI, OBS, relay-token, and WebTransport smoke
tests remain recommended for hardware-specific distribution decisions.
