Minamo v0.1.16 hardens the KGM1B decoder against malformed input and makes
the signed desktop updater manifest deterministic across release targets.

## Decoder resilience

- A dedicated `cargo-fuzz` workspace now exercises packet decoding, valid
  round trips, and corruption of otherwise valid KGM1B containers (#262).
- Seed corpus generation keeps the fuzz inputs aligned with the shared codec
  fixtures.
- CI gates the fuzz workspace with stable formatting and Clippy checks, while
  the scheduled fuzz workflow pins its nightly target and sanitizer runtime.

## Runtime performance

- The tracker loop reuses per-frame hand, face, audio, and transport objects
  instead of rebuilding equivalent arrays and records for every camera frame
  (#259).
- Regression coverage verifies that reused buffers do not leak stale landmark,
  blendshape, or transport state between frames.

## Release reliability

- Native installers remain a four-target matrix, but updater manifest uploads
  are serialized so each platform extends the same `latest.json` instead of
  overwriting entries produced by another target.
- The public release gate still validates signed Linux, Windows, Apple Silicon
  macOS, and Intel macOS updater entries before publishing.

## Verification

- `pnpm lint`
- `pnpm test`
- `pnpm verify`
- `pnpm typecheck:js`
- `pnpm build`
- `pnpm release:smoke`
- `cargo test --manifest-path crates/kgm1-codec/Cargo.toml`
- GitHub Actions CI, fuzz, release matrix, and updater-manifest validation

## Known limitations

- Windows and macOS installers still lack publicly trusted developer
  certificates. SmartScreen or macOS Privacy & Security approval may be
  required even though in-app update artifacts are cryptographically verified.
- macOS packages are ad-hoc signed but not notarized; Linux packages are not
  GPG-signed.
