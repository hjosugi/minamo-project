Minamo v0.1.14 makes the native Minamo Studio app directly downloadable for
Windows, macOS, and Linux.

## Highlights

- GitHub Releases now include Windows `.exe`/`.msi`, Apple Silicon and Intel
  macOS `.dmg`, and Linux `.AppImage`/`.deb` installers.
- A release stays in draft until all four platform builds complete, preventing
  partially populated releases from becoming the latest public download.
- README and desktop documentation now provide a direct download path,
  platform selection guidance, and explicit code-signing status.
- Windows and macOS bundle icons are generated from the checked-in Minamo
  source icon; macOS builds use an ad-hoc signature for Apple Silicon.

## Verification

- `pnpm lint`
- `pnpm test`
- `pnpm verify`
- `pnpm typecheck:js`
- `pnpm build`
- `pnpm desktop:check`
- `pnpm release:smoke`
- GitHub Actions release matrix for Linux, Windows, macOS Apple Silicon, and
  macOS Intel

## Known limitations

- Windows and macOS packages are not yet signed with publicly trusted
  developer certificates. Windows SmartScreen or macOS Privacy & Security may
  require explicit approval.
- macOS packages are ad-hoc signed but not notarized.
- Linux packages are not GPG-signed.
- Trusted code signing, notarization, and the signed updater remain tracked in
  issue #251.
