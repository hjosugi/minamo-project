Minamo v0.1.17 centralizes the desktop release contract after the v0.1.16
updater pipeline repair.

## Release contract refactor

- Release metadata validation now has one testable JavaScript entry point for
  the tag, package version, Tauri version, Cargo version, and release notes.
- The updater validator exports the required platform contract, so production
  validation and regression tests no longer maintain separate platform lists.
- Invalid updater URLs now produce an explicit validation error before a draft
  release can be published.

## Release reliability

- Native installer builds remain serialized so every target extends one signed
  `latest.json`.
- macOS Apple Silicon and Intel builds continue to produce DMGs plus signed
  `.app.tar.gz` updater archives.
- The public release gate still requires signed Linux, Windows, Apple Silicon
  macOS, and Intel macOS updater entries.

## Verification

- `pnpm lint`
- `pnpm test`
- `pnpm verify`
- `pnpm typecheck:js`
- `pnpm build`
- `pnpm release:smoke`
- GitHub Actions CI, Pages, release matrix, and updater-manifest validation

## Known limitations

- Windows and macOS installers still lack publicly trusted developer
  certificates. SmartScreen or macOS Privacy & Security approval may be
  required even though in-app update artifacts are cryptographically verified.
- macOS packages are ad-hoc signed but not notarized; Linux packages are not
  GPG-signed.
